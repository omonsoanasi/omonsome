01 nlp helpdesk ticket classifier msc research · text classification · transformer models

python / bert / hugging face

a research project exploring how transformer-based models can automatically route and prioritise helpdesk tickets. the goal was to reduce manual triage time and improve response accuracy.

case study

  • fine-tuned bert on a labelled ticket dataset, comparing against classical baselines (tf-idf + svm).
  • addressed class imbalance and domain-specific vocabulary through targeted preprocessing.
  • evaluated with macro-f1 and confusion analysis; documented failure modes for ambiguous tickets.
02 hr data integration bridge enterprise systems · oracle · mysql · mssql

laravel / oracle / mysql / mssql / rest

end-to-end ownership of a data integration layer connecting hr systems across heterogeneous databases. responsible for requirements, architecture, deployment, and documentation.

what i did

  • designed a reliable sync pipeline across oracle, mysql, and mssql with idempotent writes.
  • built operational tooling for monitoring, retries, and audit trails.
  • worked directly with stakeholders to translate business rules into schema mappings.
03 academic records management system full-stack · institutional data · workflow

spring boot / oracle / java

a records management system for academic institutions, designed around real administrative workflows rather than abstract crud.

highlights

  • role-based access and audit logging for sensitive student records.
  • bulk import/export tooling with validation and error reporting.
  • built on spring boot with oracle as the system of record.
04 language preservation platform personal project · tooling for endangered languages

python / nlp / community tooling

a personal initiative to build tools that help communities document, preserve, and study languages with limited digital resources. now taking shape as ekegusii.co.ke.

why it matters

  • tech can help keep languages alive, but only if the tools respect community ownership and low-resource constraints.
  • exploring lightweight annotation, lexicon management, and audio capture workflows.
  • designed for offline-first use and minimal infrastructure.
05 loan default prediction pipeline ml pipeline · feature engineering · evaluation

python / scikit-learn / pandas

an end-to-end machine learning pipeline for predicting loan default risk, with a focus on honest evaluation and interpretability.

approach

  • feature engineering from structured financial data; handled missingness and leakage risks.
  • compared tree-based models against logistic regression; prioritised calibration and explainability.
  • documented assumptions and limitations rather than overclaiming accuracy.
